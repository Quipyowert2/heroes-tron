
   Visual Studio C++ 6 Project files.
   
   This is the Visual C++ Project files for Heroes v0.6. Conversion by
   Stéphane Denis.
   
   Requirement:
     * MS Visual Studio 6
     * [1]SDL 1.1
     * [2]SDL Mixer 1.0.6
     * [3]Heroes source files
       
   Installation
   
   Please install SDL in <HeroesDisk>/sdl (ie, c:\sdl)
   
   Unzip VisualC.zip in <HeroesPath>/src (it will generate a
   <HeroesPath>/src/VisualC (ie c:\heroes\src\VisualC)
   
   Open the projet and compile. It should generate the heroes.exe
   program.

References

   1. http://www.libsdl.org/
   2. http://www.libsdl.org/projects/SDL_mixer
   3. http://sourceforge.net/projects/heroes/
